## 1. Track A Google Maps Inspection

- Meta-data key `com.google.android.geo.API_KEY` is bound to `@string/google_maps_key`.
- Key is isolated in Android string resources, restricted in Google Cloud Console to:
  - Package: `com.aistudio.delivery.djweq`
  - Certificate SHA-1: `e08ff88aa2de0c41eb8281fbad6b59c94d8cfd1f`

## 2. Track B Flutter Client Maps Architecture

In `flutter_client/`:
- Multiplatform map operations are abstracted via `MapPlatformAdapter` (`lib/platform/maps/map_platform_adapter.dart`).
- **Sentinel Implementation:** `SentinelMapAdapter` acts as a fail-safe null-object when Google Maps SDK is not yet initialized with an active API key.
- **Zero Hardcoded Key Invariant:** Forensic scanning verified zero Google API keys hardcoded in any `.dart` file.
- **API Key Injection Strategy:** Map API keys are resolved at runtime via `AppConfigEntity.providers.mapsApiKey` or platform manifest manifest metadata, preventing cross-tenant and cross-brand key leakage.
