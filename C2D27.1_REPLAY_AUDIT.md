## 1. Single-Use Token Architecture

Build requests and privileged mutations in the BlueSystem ecosystem require single-use authorization tokens:
- **Token Format:** `tok_<timestamp>_<entropy>`
- **Validation Engine:** Checks token existence, checks `consumed: false`, checks `expiresAt > now`.
- **Atomic Transition:** Upon consumption, token document is atomically updated via Firestore transaction to `consumed: true`. Any secondary attempt using the same token is rejected with `ERR_TOKEN_ALREADY_CONSUMED`.
