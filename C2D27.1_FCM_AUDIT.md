## 1. Multi-Device Token Routing Architecture

In `flutter_client/lib/platform/notifications/notification_adapter.dart`:
The adapter implements `registerDeviceToken({required String uid, required String token})`:

```dart
// 1. Synchronize user profile token array
final docRef = _firestore.collection('users').doc(uid);
await docRef.set({
  'fcmToken': token,
  'fcmTokens': FieldValue.arrayUnion([token]),
  'lastTokenUpdate': FieldValue.serverTimestamp(),
}, SetOptions(merge: true));

// 2. Synchronize multi-device registry with explicit platform discriminator
final deviceRef = _firestore.collection('user_devices').doc('${uid}_flutter');
await deviceRef.set({
  'uid': uid,
  'token': token,
  'platform': 'flutter',
  'updatedAt': FieldValue.serverTimestamp(),
}, SetOptions(merge: true));
```
