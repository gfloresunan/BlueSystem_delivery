**Phase:** `Phase 2D.27.1 — Flutter Integration Validation & Provisioning Closure`  
**Scope:** `Google Maps SDK for iOS, Bundle ID Restrictions & API Key Isolation`

---

## 1. Architectural Posture

In iOS, Google Maps SDK requires:
1. Google Cloud Console Maps SDK for iOS enabled under GCP project.
2. API Key restricted to iOS apps with Bundle Identifier `com.bluesystem.delivery.client`.
3. Initialization in `AppDelegate.swift` via `GMSServices.provideAPIKey("...")` or via FlutterFire / plugin bootstrap.

---

## 2. Current Implementation State

- `flutter_client/lib/platform/maps/map_platform_adapter.dart` implements `SentinelMapAdapter`.
- `SentinelMapAdapter` returns safe default values and null-markers without triggering any platform native calls:
  - `getMapCenter()` returns `null`.
  - `moveCameraTo()` completes without error.
  - `addMarker()` returns `markerId`.
  - `drawRoute()` and `clearRoute()` complete as no-ops.
- No iOS API key has been created or injected in code.
