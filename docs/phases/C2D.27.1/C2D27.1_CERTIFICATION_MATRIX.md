## 3. Certificación de Invariantes Operacionales

1. **Zero Duplication Invariant:**
   Se certifica que `flutter_client/` no posee motores de cálculo tarifario, motores de despacho o máquinas de estados de pedidos independientes. Todo estado deriva de Firestore y Cloud Functions.
2. **Zero Hardcoded Secrets Invariant:**
   El escaneo estático confirma que ningún archivo `.dart` contiene API keys, service account credentials o secretos privados.
3. **Zero Mutation Invariant (Track A):**
   Se certifica que ningún archivo de `app/` o sus subdirectorios ha sido modificado, renombrado o eliminado durante esta fase.
4. **Zero Build Invariant:**
   Se certifica que ningún comando `flutter build`, `flutter run`, `gradle` o `xcodebuild` fue ejecutado. No existen artefactos binarios generados (`.apk`, `.aab`, `.ipa`).
