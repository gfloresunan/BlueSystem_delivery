## 1. Master Gap Ledger Overview

## 2. Granular Gap Profiles

### GAP-01: Firebase Android — Secondary White-Label Apps
- **GAP ID:** `GAP-01`
- **Nombre:** Registro de Aplicaciones Android Secundarias en Firebase Console
- **Capa:** Cloud Platform / Mobile Provisioning
- **Descripción:** Las aplicaciones secundarias de marca blanca (`com.fitoni.delivery`, `com.bluesystem.delivery`) requieren estar registradas en el proyecto Firebase `bluesystem-7c9af` y reflejarse dentro del arreglo `client[]` de `google-services.json`.
- **Evidencia:** `app/google-services.json` contiene únicamente el paquete de referencia `com.aistudio.delivery.djweq` (App ID `1:514416631826:android:788b99430f87324e88b8cb`).
- **Estado Actual:** 🟡 `BLOCKED_EXTERNAL`
- **Tipo:** `BLOCKER_FOR_WHITE_LABEL`
- **BLOCKER_FOR_BUILD:** `NO` (Permite compilaciones del paquete de referencia `com.aistudio.delivery.djweq`)
- **BLOCKER_FOR_FEATURE:** `NO`
- **BLOCKER_FOR_WHITE_LABEL:** `YES` (Bloquea inicialización de Firebase en sabores de marca blanca)
- **External/Internal:** `EXTERNAL`
- **Responsable:** Operador Humano / Cloud Administrator
- **Acción Requerida:** Acceder a Firebase Console (`bluesystem-7c9af`) y registrar `com.fitoni.delivery` y `com.bluesystem.delivery`. Descargar el `google-services.json` consolidado.
- **Dependencia:** Ninguna (proyecto Firebase ya existente).
- **Riesgo:** Error de inicialización `FirebaseApp.initializeApp()` en tiempo de ejecución al ejecutar variantes comerciales.
- **Criterio de Cierre:** Presencia física de los objetos correspondientes a los paquetes secundarios dentro de `client[]` en el archivo `google-services.json`.
- **Fase Objetivo:** `Phase C2D.28`
- **Evidencia Requerida para Cierre:** Hash y contenido de `google-services.json` validado con `mobilesdk_app_id` emitido por Firebase para cada package.

### GAP-02: Firebase iOS Core Provisioning
- **GAP ID:** `GAP-02`
- **Nombre:** Registro de Aplicación iOS y Provisión de `GoogleService-Info.plist`
- **Capa:** Apple Platform / Firebase iOS
- **Descripción:** La aplicación cliente iOS (`com.bluesystem.delivery.client`) no está registrada en el proyecto Firebase `bluesystem-7c9af`, y el archivo de configuración oficial `GoogleService-Info.plist` no está presente en el workspace.
- **Evidencia:** Búsqueda recursiva en el workspace confirma 0 archivos `GoogleService-Info.plist`.
- **Estado Actual:** 🟡 `BLOCKED_EXTERNAL`
- **Tipo:** `BLOCKER_FOR_BUILD`
- **BLOCKER_FOR_BUILD:** `YES` (Impide cualquier compilación nativa física de iOS en Flutter)
- **BLOCKER_FOR_FEATURE:** `YES` (Bloquea todos los servicios Firebase en iOS)
- **BLOCKER_FOR_WHITE_LABEL:** `YES`
- **External/Internal:** `EXTERNAL`
- **Responsable:** Operador Humano / Apple Developer Administrator
- **Acción Requerida:** Registrar el Bundle ID `com.bluesystem.delivery.client` en Apple Developer Portal y en Firebase Console. Descargar el archivo oficial `GoogleService-Info.plist`.
- **Dependencia:** Registro de Bundle ID en Apple Developer Account.
- **Riesgo:** Inyección de placeholders ficticios que provocarían crash inmediato en `Firebase.initializeApp()` bajo iOS.
- **Criterio de Cierre:** Archivo `GoogleService-Info.plist` descargado directamente de Firebase Console, verificado y ubicado en la ruta canónica del runner iOS.
- **Fase Objetivo:** `Phase C2D.28`
- **Evidencia Requerida para Cierre:** Archivo `GoogleService-Info.plist` auténtico con `BUNDLE_ID = com.bluesystem.delivery.client` y `PROJECT_ID = bluesystem-7c9af`.

### GAP-MAPS-01: Google Maps Android Key Restrictions
- **GAP ID:** `GAP-MAPS-01`
- **Nombre:** Restricción de Claves de Google Maps SDK para Paquetes Secundarios
- **Capa:** Google Cloud Console / Geo Platform
- **Descripción:** La clave API de Google Maps para Android está restringida exclusivamente al paquete de referencia (`com.aistudio.delivery.djweq`) y a su SHA-1 de depuración. No incluye los identificadores de paquetes de marca blanca (`com.fitoni.delivery`).
- **Evidencia:** `app/src/main/AndroidManifest.xml` referencia `@string/google_maps_key` con restricciones fijas en GCP Console.
- **Estado Actual:** 🟡 `BLOCKED_EXTERNAL`
- **Tipo:** `BLOCKER_FOR_WHITE_LABEL`
- **BLOCKER_FOR_BUILD:** `NO` (Compila sin error; falla en runtime visual)
- **BLOCKER_FOR_FEATURE:** `YES` (Bloquea renderizado cartográfico en paquetes no autorizados)
- **BLOCKER_FOR_WHITE_LABEL:** `YES`
- **External/Internal:** `EXTERNAL`
- **Responsable:** Operador Humano / GCP Security Officer
- **Acción Requerida:** Añadir en Google Cloud Console los paquetes secundarios y sus correspondientes huellas SHA-1 a la lista permitida de la API Key. Prohibido eliminar restricciones (no usar claves universales).
- **Dependencia:** Emisión de SHA-1 oficiales para las variantes white-label.
- **Riesgo:** Mapa gris con error de autenticación `AuthorizationFailure` en Android para tenants de marca blanca.
- **Criterio de Cierre:** Confirmación documental o captura de consola de que los paquetes secundarios están incluidos en las restricciones de la clave.
- **Fase Objetivo:** `Phase C2D.28`
- **Evidencia Requerida para Cierre:** Reporte de auditoría de configuración de Google Cloud Console API Keys.

### GAP-MAPS-02: Google Maps iOS SDK Key Provisioning
- **GAP ID:** `GAP-MAPS-02`
- **Nombre:** Provisión de Clave Google Maps SDK para iOS
- **Capa:** Google Cloud Console / iOS Geo SDK
- **Descripción:** No existe una clave API provisionada y restringida para Google Maps SDK for iOS. Actualmente, el cliente Flutter utiliza `SentinelMapAdapter` para evitar crashes.
- **Evidencia:** `flutter_client/lib/platform/maps/map_platform_adapter.dart` opera bajo modo Sentinel fail-safe.
- **Estado Actual:** 🟡 `BLOCKED_EXTERNAL`
- **Tipo:** `BLOCKER_FOR_FEATURE`
- **BLOCKER_FOR_BUILD:** `NO` (El adaptador Dart compila sin clave gracias al patrón Sentinel)
- **BLOCKER_FOR_FEATURE:** `YES` (Imposible mostrar mapa real de Google en iOS)
- **BLOCKER_FOR_WHITE_LABEL:** `YES`
- **External/Internal:** `EXTERNAL`
- **Responsable:** Operador Humano / GCP Security Officer
- **Acción Requerida:** Crear una API Key en Google Cloud Console habilitada para "Maps SDK for iOS", restringida al Bundle ID `com.bluesystem.delivery.client`.
- **Dependencia:** Definición oficial del Bundle ID de iOS.
- **Riesgo:** Exposición de claves sin restricción de plataforma o consumo no autorizado de cuotas.
- **Criterio de Cierre:** Clave API creada con restricción estricta de Bundle ID e inyectada mediante configuración segura.
- **Fase Objetivo:** `Phase C2D.28`
- **Evidencia Requerida para Cierre:** Verificación de restricción de Bundle ID en consola GCP y paso del adaptador fuera de modo Sentinel.

### GAP-APNS-01: Apple Push Notification Service (.p8)
- **GAP ID:** `GAP-APNS-01`
- **Nombre:** Carga de Clave de Autenticación APNs (.p8) en Firebase Cloud Messaging
- **Capa:** Apple Developer Portal / Push Infrastructure
- **Descripción:** Para que Firebase Cloud Messaging envíe notificaciones push a dispositivos iOS, se requiere una clave de autenticación APNs (`.p8`) configurada en Firebase Console.
- **Evidencia:** `flutter_client/lib/platform/notifications/notification_adapter.dart` implementa `DarwinInitializationSettings`, pero no existe credencial `.p8` configurada en el proyecto Firebase.
- **Estado Actual:** 🟡 `BLOCKED_EXTERNAL`
- **Tipo:** `BLOCKER_FOR_FEATURE`
- **BLOCKER_FOR_BUILD:** `NO` (La app iOS puede compilar sin `.p8`)
- **BLOCKER_FOR_FEATURE:** `YES` (Bloquea recepción de notificaciones remotas en iOS)
- **BLOCKER_FOR_WHITE_LABEL:** `YES`
- **External/Internal:** `EXTERNAL`
- **Responsable:** Operador Humano / Apple Team Administrator
- **Acción Requerida:** Generar la Auth Key APNs en Apple Developer Portal (`Certificates, Identifiers & Profiles > Keys`). Cargar el archivo `.p8` en Firebase Console > Project Settings > Cloud Messaging, indicando Key ID y Team ID.
- **Dependencia:** Cuenta activa de Apple Developer Program (Organización).
- **Riesgo:** Caída silenciosa de push notifications para usuarios de iOS; degradación de tracking en tiempo real de órdenes y viajes.
- **Criterio de Cierre:** Confirmación de estado "Configured" en Firebase Console para la sección Apple App Configuration.
- **Fase Objetivo:** `Phase C2D.28`
- **Evidencia Requerida para Cierre:** Registro de configuración en Firebase Console indicando Key ID y Team ID vinculados.
