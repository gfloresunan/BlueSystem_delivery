## 1. Architectural Taxonomy of Gaps & Blockers

No todos los gaps poseen la misma naturaleza ni el mismo impacto operacional. Declarar simplemente que "existen 5 gaps" sin distinguir qué bloquea cada uno desorienta la toma de decisiones ejecutivas. 

A continuación se formaliza la clasificación taxativa de cada elemento según su impacto real:

```
                                    TAXONOMÍA DE BLOQUEADORES
                                                │
         ┌──────────────────┬───────────────────┼───────────────────┬──────────────────┐
         │                  │                   │                   │                  │
    CATEGORÍA A        CATEGORÍA B         CATEGORÍA C         CATEGORÍA D        CATEGORÍA E
    BLOCKER FOR        BLOCKER FOR         BLOCKER FOR          DEFERRED /         GOVERNANCE
       BUILD             FEATURE           WHITE-LABEL        NOT A BLOCKER           LOCK
   (Impide compilar   (Compila pero       (Afecta solo a     (Postergado por     (Bloqueo por
      binario)        falla función)      marcas blancas)      gobernanza)       regla formal)
         │                  │                   │                   │                  │
      GAP-02            GAP-MAPS-02           GAP-01             GAP-SG-01          LEVEL 6

                        GAP-APNS-01        GAP-MAPS-01                             ZERO BUILD
                        (Push iOS)          (Maps WL)                              INVARIANT
```

## 2. Granular Classification Matrix

| Categoría | Identificador | Subcutáneo / Componente | ¿Por qué pertenece a esta categoría? | Impacto Operacional Inmediato |
| :--- | :--- | :--- | :--- | :--- |
| **A. BLOCKER FOR BUILD** | `GAP-02` | `GoogleService-Info.plist` & iOS App Registration | En iOS, el compilador y los plugins de FlutterFire requieren físicamente el archivo `.plist` en el bundle para enlazar los símbolos de inicialización. Sin él, `pod install` y la compilación física fallan. | **Impide compilar físicamente cualquier IPA o bundle iOS.** |
| **B. BLOCKER FOR FEATURE** | `GAP-MAPS-02` | Google Maps SDK for iOS API Key | No impide compilar el código porque `SentinelMapAdapter` abstrae la capa cartográfica de forma segura. Sin embargo, no se puede renderizar ningún mapa real de Google en iOS. | **Impide validar la experiencia cartográfica visual en iOS.** |
| **B. BLOCKER FOR FEATURE** | `GAP-APNS-01` | Apple APNs `.p8` Auth Key | La aplicación puede construirse y ejecutarse, pero FCM no podrá despachar notificaciones push a los dispositivos Apple físicos. | **Impide validar el flujo completo de tracking y push en iOS.** |
| **C. BLOCKER FOR WHITE-LABEL** | `GAP-01` | Secondary Android Firebase Apps | El paquete de referencia (`com.aistudio.delivery.djweq`) está 100% provisionado en `google-services.json`. El gap solo afecta a variantes como `com.fitoni.delivery` o `com.bluesystem.delivery`. | **Bloquea la ejecución de sabores comerciales de marca blanca.** |
| **C. BLOCKER FOR WHITE-LABEL** | `GAP-MAPS-01` | GCP Maps API Key Secondary Packages | La clave actual valida el paquete de referencia. Si se compila bajo un package de marca blanca no registrado en GCP, el mapa aparecerá gris con error de autenticación. | **Bloquea el renderizado cartográfico en sabores de marca blanca.** |
| **D. DEFERRED / NOT CURRENT BLOCKER** | `GAP-SG-01` | Production Keystores & Release Signing | La política de seguridad corporativa reserva la firma de producción para la fase final de despliegue. Para fases de prueba, desarrollo y debug controlado, se utiliza el keystore de debug verificado. | **Cero impacto en fases previas a producción.** |
| **E. GOVERNANCE LOCK** | `LOCK-L6` | Level 6 Build Token Authorization | Aunque todos los prerrequisitos técnicos de Android de referencia estuvieran 100% listos, el agente tiene prohibido consumir tokens de build sin orden humana explícita. | **Detiene físicamente la compilación de APK/AAB.** |
| **E. GOVERNANCE LOCK** | `LOCK-L7` | Level 7 Production Deployment Gate | Ninguna auditoría técnica puede otorgar Level 7 ni autorizar release productivo por inferencia automática. | **Mantiene cerrada la puerta operativa de producción.** |
| **E. GOVERNANCE LOCK** | `LOCK-HOST` | Flutter Native Host Containers | Los directorios `flutter_client/android` y `flutter_client/ios` deliberadamente no fueron generados para proteger el Zero-Build Invariant. | **Evita la introducción de artefactos nativos fuera de control.** |

## 3. Implicaciones Estratégicas para la Planificación

1. **¿Se puede compilar Flutter Android para el paquete de referencia hoy?**
   - **Técnicamente:** Sí, porque el código está completo y `app/google-services.json` ya tiene `com.aistudio.delivery.djweq`.
   - **Gobernanza:** **NO**, porque rige el `LOCK-L6` (Level 6 no concedido) y el `LOCK-HOST` (host nativo no generado).
2. **¿Se puede compilar Flutter iOS hoy?**
   - **Técnicamente:** **NO**, porque existe un bloqueador de Categoría A (`GAP-02`).
   - **Gobernanza:** **NO**, por `LOCK-L6` y `LOCK-HOST`.
3. **¿Se pueden validar marcas blancas hoy?**
   - **Técnicamente:** **NO**, porque existen bloqueadores de Categoría C (`GAP-01`, `GAP-MAPS-01`).
   - **Gobernanza:** **NO**, porque no hay autorización humana para generar variantes comerciales.

## 4. Veredicto de Clasificación

Todos los gaps han sido desagregados rigurosamente. Queda demostrado que:
- **0** Gaps internos de código.
- **1** Blocker directo de compilación (`GAP-02` para iOS).
- **2** Blockers de funcionalidad (`GAP-MAPS-02`, `GAP-APNS-01` para iOS).
- **2** Blockers de variantes de marca blanca (`GAP-01`, `GAP-MAPS-01` para Android WL).
- **1** Elemento diferido programado (`GAP-SG-01`).
- **3** Cerraduras inviolables de gobernanza (`LOCK-L6`, `LOCK-L7`, `LOCK-HOST`).
