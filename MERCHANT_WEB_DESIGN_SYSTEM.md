# MERCHANT_WEB_DESIGN_SYSTEM.md
## Sistema de Diseño y Tokens UI

## 🎨 1. Paleta de Colores
- **Background Principal**: `slate-950` (`#020617`)
- **Background Contenedor**: `slate-900` (`#0f172a`)
- **Superficie / Cards**: `slate-800/80` (`#1e293b`)
- **Bordes / Separadores**: `slate-700/50` (`#334155`)
- **Acento Primario**: `blue-600` (`#2563eb`) / `blue-500` (`#3b82f6`)
- **Acento Éxito / Abierto**: `emerald-500` (`#10b981`)
- **Acento Alerta / Pendiente**: `amber-500` (`#f59e0b`)
- **Acento Error / Cerrado**: `rose-500` (`#f43f5e`)

---

## 🧩 2. Componentes Atomizados
- **Buttons**: Variant Primary, Secondary, Outline, Danger, Icon-Only con microanimación en hover (`scale-105`).
- **Badges**: Estado de Pedido (Pendiente, En Preparación, Listo, En Camino, Entregado, Cancelado).
- **Modals & Drawers**: Desplazamiento lateral suave con backdrop blur.
- **Data Tables**: Virtualización de filas para alta densidad de datos.
