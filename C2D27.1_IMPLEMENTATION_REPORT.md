## 2. Modification Record 1: Cloud Functions Service Hardening

- **FILE:** `flutter_client/lib/data/services/cloud_functions_service.dart`
- **REASON:** Backend `functions/src/callables/identity.ts` enforces zero-trust parameter validation (`validateSwitchContextInput`). Providing `tenantId` directly throws a security violation error: `"Violación de Seguridad: Parámetro prohibido 'tenantId' detectado en la solicitud."` The backend strictly requires `{ targetMembershipId: string }`.
- **BEFORE:**
  ```dart
  Future<Map<String, dynamic>> switchTenantContext({
    required String targetTenantId,
    String? targetBrandId,
    String? targetBusinessId,
    String? targetBranchId,
  }) async {
    final callable = _functions.httpsCallable('switchActiveTenantContext');
    final result = await callable.call<Map<String, dynamic>>({
      'tenantId': targetTenantId,
      'brandId': targetBrandId,
      'businessId': targetBusinessId,
      'branchId': targetBranchId,
    });
  ```
- **AFTER:**
  ```dart
  Future<Map<String, dynamic>> switchTenantContext({
    required String targetMembershipId,
  }) async {
    final callable = _functions.httpsCallable('switchActiveTenantContext');
    final result = await callable.call<Map<String, dynamic>>({
      'targetMembershipId': targetMembershipId,
    });
  ```
- **RISK:** Negligible. Aligns the client with the already-deployed backend security rule.
- **TEST:** Tested in `tools/c2d27_1_validation.js` (Test C2D27.1-FN-001 passed).
- **ROLLBACK:** Revert git changes on `cloud_functions_service.dart`.

## 3. Modification Record 2: AppConfig Schema Hardening

- **FILE:** `flutter_client/lib/core/config/app_config.dart`
- **REASON:** Added `createDefault` factory method, `applicationId` computed property, and `AppPlatform` / `AppEnvironment` type aliases to fulfill test matrix contracts and eliminate potential compilation ambiguities.
- **BEFORE:**
  - Enum defined as `PlatformType`, missing `AppPlatform` alias.
  - No `createDefault` factory on `AppConfigEntity`.
  - Missing `applicationId` direct getter on `AppConfigEntity`.
- **AFTER:**
  - Added `typedef AppPlatform = PlatformType;`
  - Added `typedef AppEnvironment = EnvironmentType;`
  - Added `factory AppConfigEntity.createDefault(...)`
  - Added `String get applicationId => distribution.applicationId;`
- **RISK:** Zero. Strictly additive changes with zero breaking impact on existing consumers.
- **TEST:** Tested in `tools/c2d27_1_validation.js` (Test C2D27.1-CFG-001 passed).
- **ROLLBACK:** Revert git changes on `app_config.dart`.
