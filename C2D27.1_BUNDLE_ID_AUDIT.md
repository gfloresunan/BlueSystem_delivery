## 2. Collision & Forking Analysis

- **Zero Code Forks:** The package identity is managed through `AppDistributionConfig.applicationId` and `bundleId` within `AppConfigEntity`.
- **Dynamic Configuration:** Code never branches on hardcoded package strings; instead, identity is resolved from the loaded `AppConfig` document.
- **Uniqueness Assurance:** Android `applicationId` and Apple `bundleId` are distinct and cannot collide in platform registries.
