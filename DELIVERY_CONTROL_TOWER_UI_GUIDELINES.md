# DELIVERY CONTROL TOWER (DCT) UI GUIDELINES
**BlueSystem Delivery Enterprise v2.1 (Sprint 15.2)**

---

## 1. Principios de Diseño UX/UI

Inspirado en Uber Eats Merchant, PedidosYa Partner, Toast POS, Shopify POS y Google Maps Fleet Engine:

1. **Información Crítica Siempre Visible**: Todos los indicadores esenciales a la vista en < 3 segundos.
2. **Regla de Máximo 3 Toques**: Cualquier acción operativa se completa en un máximo de 3 toques.
3. **Fondo Dark Mode Nativo en Mapa**: El Mapa Operacional utiliza el contenedor `Color(0xFF0F172A)` para reducir el cansancio visual en entornos de restaurante.
4. **Accesibilidad WCAG AA**: Contrastes elevados para semáforos de SLA y alertas.
