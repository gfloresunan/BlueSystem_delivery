# ADR-011.3 — Phase 3.5 CERTIFICATION: Merchant Onboarding Infrastructure Remediation

**System:** BlueSystem Delivery Enterprise v2.2

**Date:** 2026-08-09  
**Status:** 🟢 **CERTIFIED — E2E VERIFIED**

---

## 1. Scope of Remediation

Phase 3.5 addressed critical infrastructure failures in the Merchant Onboarding Portal pipeline identified during ADR-011.3 forensic audit:

| Issue | Root Cause | Fix Applied | Status |
|---|---|---|:---:|
| CORS block on callable | Functions not deployed | Deployed all 4 callables | ✅ |
| False Success UX | Client Firestore fallback | Eliminated fallback entirely | ✅ |
| Duplicate applications | No server-side check | Backend query + `already-exists` | ✅ |
| Public direct create | Permissive Firestore rules | `allow create: if isPlatformAdmin()` | ✅ |
| Missing `documents` in payload | Field not in interface | Added to `MerchantApplicationPayload` | ✅ |
| Error UX undifferentiated | Generic catch-all | Business vs. infrastructure mapping | ✅ |

### 3.6 Fallback Elimination

- False success modal on callable failure: **ELIMINATED** — errors now propagate to UI error panel with retry button
