## 2. Invariant: Non-Duplication of Order State Machine

- **No Second State Machine:** The Flutter client does not implement autonomous state machine logic or calculate delivery fees client-side.
- **Order Creation:** Order creation is processed via authoritative backend triggers and Cloud Functions (`createAuthoritativeOrder`).
- **Status Updates:** Couriers and merchants submit state transitions that are evaluated server-side against business integrity rules.
