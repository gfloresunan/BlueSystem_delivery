## 2. Flutter Client Android Manifest Readiness

Because Phase 2D.27.1 adheres strictly to the **ZERO BUILD / ZERO GRADLE / ZERO FLUTTER RUN** rule:
- The native Android project wrapper (`flutter_client/android/`) has **NOT** been generated or executed.
- The manifest specifications required for future Flutter Android execution are fully defined:
  - **Network:** `INTERNET`, `ACCESS_NETWORK_STATE`
  - **Location:** `ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`
  - **Push Notifications:** `POST_NOTIFICATIONS` (Android 13+)
  - **Component Security:** All exported activities must explicitly set `android:exported="true"` with appropriate intent filters; unexported components must set `android:exported="false"`.
